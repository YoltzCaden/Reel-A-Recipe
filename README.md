# Reel-A-Recipe
This is a project that is **in planning**.

Project Idea - A social media app for cooks to share their meals with recipes to consumers.
Most videos are tailored to the ingredients in your food inventory. Food Preferences are picked at the start when log into the app.

Key Features:
- A user can create a short video (cooking content only)
- A user needs to add recipes to their videos
- A viewer can add recipes from video to a shopping list
- All users have a food inventory
